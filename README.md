# البدر مباشر — Al-Badr Live Lessons

Android app for the live and recorded lessons of Sheikh Abdurrazzaq al-Badr at the Prophet's Mosque, Madinah:
the live stream, the recordings of each course, the book being read, and a notification when a lesson starts.
Unofficial app.

This repository holds only the app's releases (signed APK files). It contains no source code.

## Install with Obtainium

[Obtainium](https://github.com/ImranR98/Obtainium) installs the app from these releases and keeps it updated.

1. Install Obtainium.
2. In Obtainium, tap **Add App** and paste:

       https://github.com/abumalick/albadrmubasher

3. Tap **Add**, then **Install**. Allow Obtainium to install apps when Android asks.

Obtainium then offers each new version as it is released here.

You can also download `albadr-mubasher.apk` directly from the
[latest release](https://github.com/abumalick/albadrmubasher/releases/latest).

## Google Play

The app is also on [Google Play](https://play.google.com/store/apps/details?id=com.albadrmubasher.app).
The Play copy and this one are signed differently, so neither can update the other: to switch, uninstall
the one you have first.
